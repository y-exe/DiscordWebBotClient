# 使い方

## ログイン

1. `/login` を開く
2. User Token(セルフボット)/ Bot Token のいずれかを入力してログイン
3. トークンはサーバー側の HttpOnly Cookie に保存され、最大 5 スロットまで履歴として残ります
4. 次回以降は履歴からワンクリックで再ログインできます(スロット単位で削除も可能)

## 画面構成

- **サーバーリスト(左端)**: サーバーの一覧。フォルダーに整理でき、ドラッグ&ドロップで並べ替えられます
- **チャンネルサイドバー**: カテゴリ / テキスト / ボイス / フォーラム / スレッド。DM ではフレンドとグループ一覧
- **メッセージタイムライン**: 中央。グループ化されたメッセージ、埋め込み、添付、スタンプを表示
- **メンバーリスト(右)**: サーバー時に表示。ユーザーをクリックでプロフィールポップアウト

## メッセージの操作

| 操作 | 方法 |
|---|---|
| 送信 | 入力欄から。ファイルは 10 件まで添付可能 |
| 編集 / 削除 | 自分のメッセージを右クリック |
| 返信 | メッセージを右クリック → 返信 |
| リアクション | メッセージ右クリックまたは既存リアクションの + ボタン |
| ピン / 検索 | チャンネルヘッダーから。ピン留め一覧・チャンネル内検索が開けます |
| 既読 / ミュート | チャンネル右クリック → 既読にする / ミュート / 通知設定 |

## スラッシュコマンド

1. 入力欄に `/` を入力するとコマンド一覧が補完されます
2. オプションを持つコマンドは Enter でオプション入力モーダルが開きます
3. 文字列 / 選択肢 / 数値 / 真偽値 / ユーザー・チャンネル・役職(一覧から選択)に対応しています
4. 「実行」で interaction として送信され、ボットの応答が表示されます
