# 設定

設定画面は左下の自分のアイコン →「ユーザー設定を開く」、サーバー / チャンネルの右クリックメニューからも開けます。

## ユーザー設定

| ページ | 内容 |
|---|---|
| アカウント | 表示名、カスタムステータス、ステータス(オンライン / 退席中 / 取り込み中 / オフライン) |
| プロフィール | アバター、バナー、一人称、自己紹介 |
| セッション | 現在のログイン状態の確認とログアウト |
| 外観 | テーマ(ライト / ダーク)、アクセントカラー、フォント、メッセージサイズ / 間隔 |
| 通知 | 通知の有効化、サウンドなどの挙動 |
| 言語 / 詳細 | 表示言語、初期設定へのリセット |

外観の設定値はブラウザーの localStorage(`discord-webclient-settings-v1`)に保存されます。

## サーバー設定

| ページ | 内容 |
|---|---|
| 概要 | サーバー名、アイコン、説明の編集 |
| 役職 | 作成 / 編集 / 削除、色、権限、表示順 |
| メンバー | ニックネーム変更、キック、BAN、タイムアウト |
| 招待 | 招待リンクの作成 / 一覧 / 失効 |
| BAN | BAN 一覧と解除 |
| 絵文字 / スタンプ | カスタム絵文字・スタンプの追加 / 編集 / 削除 |
| 通知 | サーバー既定の通知とミュート |
| 監査ログ | 変更履歴の閲覧 |

## チャンネル設定

| ページ | 内容 |
|---|---|
| 概要 | チャンネル名、トピック、スローモード、年齢制限 |
| 権限 | 役職 / メンバーごとの権限上書き(許可 / 未設定 / 拒否) |
| ウェブフック | 作成 / 編集 / 削除、URL のコピー |

権限の変更はスティッキーパネルの「保存」でまとめて適用されます。
